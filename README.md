# Candopia

Match-3 candy puzzle game (Godot 4.7.2, Android) by Jiyansh Studio.

100 levels, 10 worlds, HD candies (512x512), 4K backgrounds (2160x3840),
9x9 boards on the later levels.

## Releases

Download the Android APK from the
[Releases](https://github.com/neelkiru10-lang/Candopia/releases) page.

## Build

Open the project in Godot 4.7.2 and export the "Android APK" preset.
